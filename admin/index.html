Admin — CONSTITA

Arraste as fotos para a categoria. Elas são salvas em img/<categoria>/ e enviadas ao GitHub em um único commit.

1. Conexão com o GitHub

Crie em GitHub → Settings → Developer settings → Fine-grained tokens, só neste repositório, com Contents: Read and write. Fica salvo apenas neste navegador.

2. Adicionar peças

Solte uma ou várias fotos sobre a categoria (ou clique nela para escolher os arquivos).

3. Peças publicadas

Edite nome, preço, estoque ou desative peças. Estoque 0 mostra “Esgotado”.

Conecte ao GitHub para carregar.
